## Featured work

### 🌐 Low-Resource Hindi Language Modeling
[Repository ↗](https://github.com/rohitkrtiwari/Low-Resource-NLP-Indian-Language-LLMs) · Collaboration with **Rohit Tiwari**

Compared BPE and morpheme-based tokenization for GPT-2 on Hindi text. The morpheme model reached **18.7 perplexity** versus **24.3** for BPE — a reported **23% reduction**.

### 🧠 Reliable Code Generation & Hallucination Mitigation
**M.Tech thesis · Indian Institute of Technology Jammu**

A Python code-reliability framework combining execution and static-analysis signals with model explanations to guide refinement. The detector achieved **83.58% accuracy** (Macro-F1 **0.83**); MBPP strict accuracy was **86.34%** for the full system versus **84.70%** for the baseline. The **90.66%** full-set result was projected, not measured.
